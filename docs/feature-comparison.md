# 功能对账：Flutter 主实现 vs PowerShell 遗留版（PROP-18）

> 本文档为 `SyncthingIgnoreGUI`（Flutter 桌面版，主实现，当前 v1.33.0）与遗留
> `SyncthingIgnoreGUI.ps1`（PowerShell WinForms，维护态，v1.18.5）的能力对账。
> 遗留版仅作兼容保留，新功能与修复均在 Flutter 版进行。

## 能力矩阵

| 能力 | Flutter 版 | PowerShell 版 | 说明 |
|------|:---:|:---:|------|
| 扫描 `.stignore` 文件（含映射盘 / UNC） | ✅ | ✅ | 两者均支持 |
| 应用标准规则（SHA-256 比对 + 写前备份 + 轮转） | ✅ | ✅ | 逻辑等价 |
| 仅预览（不写入文件） | ✅ | ✅ | |
| 强制清理失效路径 | ✅ | ✅ | |
| 中英双语界面（运行时切换） | ✅ | ✅ | |
| 明暗主题 | ✅ | ❌ | PowerShell 版仅跟随系统主题 |
| 窗口位置 / 尺寸记忆 | ✅（仅 Windows） | ❌ | Flutter 版依赖 Win32；跨平台未实现 |
| 忽略清单在线更新 | ✅ | ❌ | |
| 应用前确认 + 实时状态行 | ✅ | ⚠️ | PowerShell 版有确认，状态提示较弱 |
| 应用更新检查与一键下载安装 | ✅ | ❌ | |
| 窗口拖拽填入路径 | ✅ | ❌ | |
| 备份管理（恢复 / 删除） | ✅ | ❌ | |
| 失败状态行透出（PROP-16） | ✅ | ❌ | |
| 日志导出为文件（PROP-17） | ✅ | ❌ | |
| 应用后合规重算（PROP-14） | ✅ | ❌ | |

## 使用边界

- **推荐**：新用户与日常使用请采用 Flutter 桌面版（`app/`），功能完整且持续维护。
- **遗留版**：`SyncthingIgnoreGUI.ps1` 仅在无 Flutter 运行环境的 Windows 上作应急兼容使用；不保证与 Flutter 版行为完全一致，亦不再接收新功能。
- 规则集（`.stignore`）两版共用，版本独立演进（当前规则集 v1.18.5）。
