# 2026-09-24

## 修复 CI `flutter test --coverage` 写盘回归用例偶发失败
- CI `build-windows` 作业 `flutter test --coverage` 报 `settings_store_test.dart: AppState writes language/theme changes back to disk` 失败（78 passed, 1 failed）。
- 根因：该用例用 `_waitFor` 轮询磁盘（100×20ms=2s 超时）等待 AppState 的 fire-and-forget 写盘；写队列串行逻辑本身正确（最终值必为 (zh,false)），但在 CI `--coverage` 慢环境下轮询偶发超时，属 v1.22.0 同类 flaky 复发。
- 修复：`services/settings_store.dart` 新增 `Future<void> get idle => _queue;`（暴露写队列尾）；`test/settings_store_test.dart` 删除易超时的 `_waitFor`，失败用例改为 `await store.idle;` 后 `store.load()` 断言。改为确定性等待，消除时序依赖。
- 验证：本机 `flutter test` 与 `flutter test --coverage`（仅该文件）均 10/10 通过。
- 版本提示：真实 HEAD 的 `AppState.version` 已是 `1.25.3`（与本地工作树 `VERSION` 的 1.22.0 不一致，autocrlf 行尾伪差异掩盖了 git diff）；若 CI `validate` 三轨校验报失败需同步统一版本，本次未擅自改动。
