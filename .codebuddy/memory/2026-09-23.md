## 减小 flutter_windows.dll 体积（咨询，本日下午）
- 事实：`flutter_windows.dll` 是 Flutter SDK **预编译引擎**（Skia/Impeller + Dart 运行时 + D3D 后端），正常 `flutter build windows` 无法改其内容/体积。
- 正常构建无法缩小；唯一真能减体积的路径是**自定义引擎编译**：`gn` 参数 `optimize_for_size=true` + 关闭非 Windows 后端 `enable_gl=false`/`enable_vulkan=false`/`enable_metal=false` + `enable_skia=false`（仅留 Impeller）+ `dart_runtime_mode="release"`/`symbol_level=0`，再 `flutter build windows --local-engine=windows_release --local-engine-src-path=<engine src>`。
- 取舍：自定义引擎需 depot_tools、编译耗时、且破坏 CI 可复现（CI 须自编译引擎），对单体小工具通常不划算。
- 更"规范"的折中：接受引擎体积，靠 §9.5 的 zip 高压缩（SmallestSize/7z -mx9）+ 上轮 `--tree-shake-icons` 减小资源；分发层 UPX 压 dll 有运行期/杀软风险，不推荐。
