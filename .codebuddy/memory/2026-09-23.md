## 扫描/替换自动跳过应用自身目录的 .stignore（v1.19.1）
- 用户要求「扫描和替换时自动忽略本应用目录里的忽略清单文件」。根因：`app_state.scan()` 调 `scanRoots` 未传 `skipDir`，且 `applyRules` 的 `sourcePath` 指向 `manifestPath`（而非规则源），导致扫描全盘时会找到 exe 目录里提取出的 `assets/.stignore`，并在「替换」时覆盖 → 自伤打包规则。
- 修复：
  - `services/scanner.dart`：`findStignoreFilesRaw` 始终把 `p.dirname(Platform.resolvedExecutable)` 加入跳过集；`skipDir` 由精确匹配单目录改为「目录+全部子目录」整体跳过（`_isWithinOrEquals` 大小写不敏感）。
  - `services/applier.dart`：`applyRules` 新增可选 `List<String>? skipRoots`；命中应用目录的清单项静默跳过（`log('skippedAppDir::...','muted')`），不备份/不写（既存清单兜底）。
  - `state/app_state.dart`：新增 `appDirectory` getter；`scan()` 传 `skipDir: appDirectory`、`apply()` 传 `skipRoots: [appDirectory]`。
  - `i18n.dart`：新增 `skippedAppDir`（en/zh）。
- 测试：`scanner_test` 改为验证 `skipDir` 子树跳过（嵌套 `.stignore` 同样排除）；`applier_test` 新增 `applyRules skips paths inside skipRoots`。本机 `flutter analyze` 0 问题、`flutter test` **13/13** 通过（原 12）。
- 版本：修复 → PATCH 升 **v1.19.1**，同步 6 处 Flutter 轨（VERSION / pubspec `1.19.1+1` / `AppState.version` / `manifest.dart` 示例 / README+README_EN 徽章与正文）+ 根 CHANGELOG + `docs/project.md` §3·§4·§7·§8·§9.4·§9.5 + `docs/development-tasks.md`。三轨一致：Flutter 1.19.1 / PowerShell 1.18.5 / 规则集 1.18.5。
- 注：`app/pubspec.lock` 内该包 `version: "1.19.1"` 同步（pub get 重写）；本机 `flutter pub get --offline` 可用（依赖未变）。`app/_verify.log` 被 `.gitignore` 的 `*.log` 覆盖，未提交。
