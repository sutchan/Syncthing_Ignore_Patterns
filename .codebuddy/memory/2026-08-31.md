- `**/vendor/` 含斜杠 → 不匹配同步根级 `vendor/`（只匹配子级）。
- `**/*.db` 误伤真实 SQLite 数据；`*.lock` 误伤 `Cargo.lock`。
- `**.stfolder/` 与文件内注释矛盾（注释警告忽略会破坏 folder marker，却仍忽略）；`**.stversions` 同理。
