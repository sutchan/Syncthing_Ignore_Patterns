## .stignore 规则集审查（v1.14.x，仅审查未改文件）

实测数据：16 个分类注释、225 条规则、无完全重复行。

关键缺陷（已用近似 Syncthing pattern→正则脚本验证）：
- `/node_modules/**` 为根锚定，嵌套 node_modules（monorepo 子包）不忽略。
- `**/.vscode/*` 只匹配直接子项，`.vscode/extensions/**` 等深层文件漏网；`!/.vscode/settings.json` 仅恢复根级。
- `**/.swp` / `**/.swo` 匹配不到 vim 真实交换文件（`.foo.swp`），应为 `**/*.swp` / `**/*.swo`。
- `**/vendor/` 含斜杠 → 不匹配同步根级 `vendor/`（只匹配子级）。
- `**/*.db` 误伤真实 SQLite 数据；`*.lock` 误伤 `Cargo.lock`。
- `**.stfolder/` 与文件内注释矛盾（注释警告忽略会破坏 folder marker，却仍忽略）；`**.stversions` 同理。
- 宽泛误伤：`**download/`、`**downloads/`、`**Cache*`、`**Internet*`、`**log/`、`**logs/`、`**metadata/`、`**packages/`、`**thumb/`。

缺口：缺 `**/target/`（Rust）、`**/bin/`、`**/obj/`、`**/dist/`、`**/build/`、`**/*.pyc`、`**/*.class`；建议忽略 GUI 自身备份 `**/.stignore.bak.*`、`**/stignore-paths.json.bak.*`。
