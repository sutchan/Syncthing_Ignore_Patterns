## CI 修复（v1.29.1）
- `validate` 作业「文档与变更日志引用当前版本」步骤（ci.yml 行 173–197）原两缺陷：① `pat = "如 \`$ver+1\`"` 误用反斜杠+反引号转义，使闭合 `"` 被转义为字符串内字面引号，字符串未闭合，ParserError 吞掉后续行致整步失败；② `-like "*pat*"` 把 `## [vX]` 的 `[...]` 当通配符字符集，匹配不上 CHANGELOG 字面 `## [vX]`，解析修好后会立即误报。
- 修复：`pat = "如 \`\`$ver+1\`\`"`（双反引号产生字面反引号且 `$ver` 插值）；匹配改 `$content.Contains($c.pat)` 字面子串。本地纯英文脚本验证双反引号转义（结果含字面反引号）+ `.Contains` 命中 `[v1.29.1]`（`-like` 同模式返回 False 印证原必误判）。
- 改动 `ci.yml`（配置）按规则 bump patch 1.29.0 → 1.29.1，同步 6 处单一来源 + 两 README + tasks.md + project.md 5 个当前展示位 + CHANGELOG/project.md §7 新增 v1.29.1 条目；历史 v1.29.0/v1.28.7 条目保留。
- 注：本机仅 Windows PowerShell 5.1（非 pwsh 7），UTF-8 无 BOM 的 .ps1 被当 ANSI 读致中文乱码假报错；CI 真实解析以 Linux pwsh 7（UTF-8）为准，本地仅用英文片段验证语法语义。
