## 修复扫描进度卡顿 bug (v1.7.0)
- 根因：`btnScan.Add_Click` 在 GUI 事件线程**同步**调用 `Start-ScanJob` → `Start-ParallelScan.EndInvoke` 阻塞 GUI 线程直到全盘扫描完成，期间窗口无法刷新、进度条 marquee 不动、日志不滚动，表现为"卡顿"。
- 修复：把扫描核心抽成无 UI 函数 `Invoke-ScanCore`（仅计算 roots + 调并行扫描返回原始记录）；`btnScan` 改为用后台 `[powershell]::Create().BeginInvoke()` 运行 `Invoke-ScanCore`，并启动 `System.Windows.Forms.Timer`（100ms）持续 `DoEvents()` 保持 UI 响应；Timer 回调检测 `IsCompleted` 后在 GUI 线程汇总写清单/日志/Set-Busy。预览模式仍走原 `Start-ScanJob`（轻量无需后台）。
- 版本升至 v1.7.0，同步 README/README_EN 徽章与 openspec CHANGELOG。
- 仍**未 git 提交**。
