## PowerShell → Dart+Flutter 桌面版重写（v1.18.5 启动）
- 目标：把 `SyncthingIgnoreGUI.ps1`（PowerShell WinForms）重构为 `app/` 下的 Dart+Flutter Windows 桌面应用，构建为独立 `.exe`。功能对齐：扫描 `.stignore`（DFS 跳过 `.git`/规则源目录、每根目录 isolate 并行≤4）、应用标准规则（SHA-256 比对跳过一致、写前 `.bak.<时间戳>` 备份、`<base>.bak.*` 轮转≤3、`force` 才清理失效路径）、中英双语（`i18n.dart` 键对齐原 `$T`）、明暗主题。
- 模块拆分（纯逻辑可单测）：`lib/services/scanner.dart`、`applier.dart`、`rules_source.dart`、`platform_io.dart`（win32 枚举固定驱动器）；`lib/models/manifest.dart`；`lib/state/app_state.dart`；`lib/ui/home_page.dart`；`lib/i18n.dart`；`lib/main.dart`/`app.dart`。
- 标准规则集作为资源 `app/assets/.stignore` 打包（由根 `.stignore` 复制），运行时 `rootBundle` 加载；更新规则须同步该副本。
- 测试：`app/test/scanner_test.dart`、`applier_test.dart`；覆盖率用 `dart-collect-coverage` 技能：`flutter test --coverage` 生成 `coverage/lcov.info`（`coverage` 已入 dev_dependencies）。
- 构建：`cd app && flutter config --enable-windows-desktop && flutter pub get && flutter build windows` → `build/windows/x64/runner/Release/syncthing_ignore_gui.exe`。
- **环境限制**：本机 `flutter/dart` 已装（E:\Program Files\Flutter），但 `flutter pub get` 因无外网访问空闲超时，无法在会话内完成依赖拉取/编译/构建；需在新对话（有网络）中执行 pub get + test + build。
