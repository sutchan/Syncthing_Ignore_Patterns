## file_picker analyze 修复 (v1.18.9)
- 用户 CI/`flutter analyze` 报错：`FilePicker.platform` getter 未定义（undefined_getter，app_state.dart:95/105）。根因：`file_picker` 11.0.0 起移除 `FilePicker.platform` getter，方法改为静态（`FilePicker.getDirectoryPath()`/`FilePicker.saveFile()`）；原 `^8.0.0` 约束在解析到 11+ 时即报错。
- 修复：pubspec.yaml `file_picker: ^8.0.0` → `^11.0.0`（11.x 仍兼容 `win32 ^5.5.0`，无需升 win32；12+/13+ 会经 windows_file_picker 强制 `win32 ^6.3.0` 冲突，故停在 11）；app_state.dart 两处 `FilePicker.platform.x` → `FilePicker.x`。
- 验证：本地 `flutter pub get`→11.0.3，`flutter analyze` No issues，`flutter test --coverage` 7/7 通过。版本全链路升 1.18.9（VERSION/pubspec `1.18.9+1`/AppState.version/manifest 示例/README 徽章与正文/docs/project.md/docs/development-tasks.md/CHANGELOG 新增小节）。`.stignore` 规则集轨与 PowerShell 轨保持 1.18.5 不动。
- 经验教训：file_picker API 在 8.3.7/9.2.3/10.3.10 仍保留 `platform` getter，11.0.0 起改静态；升级该依赖须同步改调用方式，否则 analyze 在 CI 用新锁时失败。
